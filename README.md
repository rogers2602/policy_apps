## 🚀 Como ativar o GitHub Pages

1. Acesse o repositório no GitHub: **[github.com/rogers2602/policy_apps](https://github.com/rogers2602/policy_apps)**
2. Vá em **Settings** > **Pages**
3. Em **Build and deployment > Branch**, selecione:
   - Branch: `main`
   - Pasta: `/ (root)`
4. Clique em **Save**. Em instantes, o site estará disponível no ar!
